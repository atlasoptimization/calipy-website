Calibration with CaliPy

Probabilistic models
for sensors and instruments.

CaliPy is a calibration library for Python. It connects physical relationships, unknown quantities, and measurement uncertainty in a model you can run and inspect.

Follow a simple calibration →

The calibration question

Relate what the sensor reads
to what you want to measure.

A reading may include an offset, a changing response, drift, and random variation. Calibration uses reference information and observations to learn the quantities that describe that relationship.

A probabilistic model also represents uncertainty. It asks which parameter values are plausible under the data and assumptions, rather than only returning one fitted curve.

A minimal example

A sensor reads about 0.45 °C high.

At an exact 20 °C reference, eight illustrative readings lie between 20.36 and 20.52 °C. Estimate a shared offset while keeping measurement noise separate from uncertainty about that offset.

Core concepts

How a CaliPy model is organized.

The same scientific explanation can be expressed in Python and inspected through the development workbench.

Quantities
Known values, fitted point parameters, or prior-backed unknowns, each with a scientific role.
Effects
Reusable transformations and probability laws that describe how quantities become readings.
Named dimensions
Axes such as sensor, repetition, or time that keep the meaning of the data visible.
Observations
Measured data connected to stochastic model outputs.
Inference and checks
A computational method for learning the unknowns, followed by diagnostics and validation for the intended use.

From a small model to more complex instruments

Compose physical
and statistical relationships.

A constant offset is only a starting point. Sensor response, geometry, environmental dependence, and structured variation can require a richer probabilistic model.

CaliPy builds on PyTorch and Pyro. Current development also explores learned response maps and approximate posterior models. Those deep-modeling capabilities remain experimental; the available public package and preview APIs differ.
