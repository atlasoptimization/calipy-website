What is the steady reading behind the warm-up?

Imagine a sensor that starts near 20 °C and approaches a steady 24 °C. We generate 64 readings over eight minutes with independent Normal noise of known standard deviation 0.15 °C. The task is to recover the steady level, initial deviation, and settling time.

A constant baseline uses the average of the training readings. CaliPy fits an exponential warm-up model. Both are evaluated on the same 16 readings held out before fitting.

Three quantities. One measurement law.

m(t) = T∞ − ΔT exp(−t / τ)
y(t) ∼ Normal(m(t), 0.15)

CaliPy connects the unknown steady level, positive initial deviation, and positive time constant to an observed reading dimension. The equation remains ordinary Python and Torch; the model retains an explicit probability law.

Core model · development API
@cp.block
def model(time: observation):
    return measurement(
        loc=steady() - drop() * torch.exp(-time / tau())
    )

The fit uses cp.SVI.map: 1,500 optimization steps, learning rate 0.025, and seed 23. Priors are Normal(24, 2) for the steady level, LogNormal(log(4), 0.35) for the deviation, and LogNormal(log(2), 0.35) for the time constant. These are MAP point estimates. They do not describe posterior parameter uncertainty.

Take the evidence with you.

The standalone script regenerates the data, fits the model, computes the baseline comparison, and writes a figure and numerical record. Every fourth reading, starting at index zero, is held out.

From this example to your instrument.

This demonstrates an inspectable path from a physical equation to a fit and a held-out comparison. The holdout is interleaved within one simulated run: it tests interpolation, not performance on a new sensor, a future campaign, or an unseen operating regime.

A real study needs suitable reference measurements, noise checks, repeat experiments, an identifiability assessment, and validation appropriate to the decision. If uncertainty in the fitted quantities matters, use and assess posterior inference rather than treating a MAP fit as an uncertainty estimate.
