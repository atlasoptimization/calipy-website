Learning path / first model

Estimate an unknown mean:
your first model.

Three short lessons connect a measurement question to the model and the evidence. You can follow the browser exercise without installing anything.

On this page

1. Tell the measurement story2. Inspect the model3. Read the evidenceContinue in Python

Lesson 01 / What are we trying to learn?

The readings vary. The level is unknown.

Imagine repeated measurements of a stable level. We use eight illustrative readings, a known measurement-noise standard deviation of 0.2, and an unknown scalar level μ. The level has a Normal(0, 5) prior: the 5 is a standard deviation.

μ ∼ Normal(0, 5)
yᵢ ∼ Normal(μ, 0.2)

The first statement describes uncertainty about the level before the readings. The second describes how readings vary around that level. This example assumes independent measurement errors conditional on μ and a known, constant noise scale.

Check your understanding: are the two standard deviations the same kind of uncertainty?

No. The prior scale describes uncertainty about the shared level. The measurement-noise scale describes variation in individual readings around that level. More readings can sharpen inference about μ without removing measurement noise.

Lesson 02 / Find the scientific objects

Inspect the model in the browser.

Open the browser demo. Follow the guided sequence, or select model objects yourself. Find the unknown level, the measurement law, and the observed readings. Inspect the object descriptions and how the pieces connect.

  1. Locate the shared unknown μ and inspect its prior.
  2. Find the measurement-noise scale and the observed values.
  3. Follow the route from the unknown level to the readings.
  4. Use the recorded inference step to reveal the stored result.
Try the browser demo →

The browser uses the real GUI renderer with a fixed example. It replays recorded results; it does not run inference or let you fit edited data. Return here after exploring.

Check your understanding: what would change if each sensor had its own unknown level?

The model would need a sensor dimension and a decision about how those levels relate. Sharing one μ across all sensors would impose a different scientific assumption. A plausible diagram alone cannot decide which assumption is right.

Lesson 03 / Ask what the result supports

Interpret the recorded posterior.

The stored demo run uses NUTS with 100 warm-up steps and 320 retained draws in one short chain. It puts the mean of μ near 2.0, with posterior standard deviation about 0.068. The corresponding analytic Normal-posterior standard deviation is about 0.071.

These values describe uncertainty about the unknown level under this model. Predictions of a new noisy reading also include measurement variation. The short chain is teaching evidence; it does not establish convergence or performance for another model.

Check your understanding: does a narrow posterior prove that the instrument is accurate?

No. The model could omit bias, drift, correlation, or uncertainty in the assumed noise scale. Posterior precision is conditional on the model and data. Validation needs checks against the scientific question and suitable independent evidence.

In the demo, inspect the recorded evidence and download its matching Python example if you want to reproduce that specific run.
