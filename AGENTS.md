# CaliPy website instructions

## Scope

This is the independent website repository for `calpymodels.com`. Make website
edits here. Do not modify the sibling CaliPy library checkout as part of website
work without an explicit user request. Do not stage, commit, push, or change
hosting or DNS unless explicitly requested.

## Reference context

The user has authorized this website task to consult the sibling
`../calipy_codex/` checkout as a read-only reference. Read this README for the
website brief. For content changes, consult the relevant sources there:

- `README.md` and `docs/source/index.rst` for the project introduction.
- `docs/source/start/modeling_idea.md` for the modeling explanation.
- `docs/development/CALIPY_CONTEXT.md` for current behavior and known limits.
- `docs/development/CALIPY_FUNCTIONALITY_MAP.md` and the corresponding code,
  tests, or examples when verifying a specific capability.

These references are not copied or automatically loaded into this repository.
If the sibling checkout is unavailable or access is restricted, ask for its
location or access; do not invent project facts. Do not transfer internal notes
or working data into public page content. Keep current behavior, experimental
features, and future plans distinct. Preserve the CaliPy spelling.

## Implementation

Keep the initial site static and dependency-free. Preserve semantic HTML,
keyboard focus visibility, responsive layout, and the pre-alpha label. Check
the page in a browser at desktop and narrow widths after visual changes. Read
the current files and Git status before editing; preserve existing work.
