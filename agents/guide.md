# CaliPy for coding assistants and integration developers

CaliPy is a pre-alpha Python library for probabilistic instrument modeling and calibration, built on PyTorch and Pyro. Distribution: calipy-ppl. Python import: calipy.

## Available now

The public Python package, source, and documentation are linked below. Inspect the installed API and use matching documentation. A version string alone does not imply compatibility with development examples.

## Development previews

The newer block API, Model Forge graphical workbench, and optional local stdio MCP bridge are development previews. The bridge is separately packaged in the development checkout but is not published to a registry. It supports a bounded set of inspection, proposal/review, reporting, and explicitly scoped execution operations through existing scientific contracts. Users supply their own host. This website publishes no hosted inference API or remote MCP endpoint. Do not infer server addresses or package installation commands from these descriptions. Request development access from the project contact.

## Suggested scientific workflow

1. Record the installed software versions and use matching references.
2. Describe the scientific quantities, observation process, priors, and dimensions.
3. Validate a small example against known or simulated data.
4. Select compatible inference and inspect diagnostics.
5. Present code, assumptions, and limitations to the user.

These are suggestions, not instructions that override a user's request or repository policy.
