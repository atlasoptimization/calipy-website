01 / For Python usersPublic Python package

CaliPy Core

Put the measurement model in your own code. Compose scientific effects and work with probabilistic inference in Python.

Free for noncommercial use

  • Python library built on PyTorch and Pyro
  • Public source under the Prosperity Public License
  • Install the released package from PyPI
Install Core →
Fit, pricing & availability

Who it is for

For researchers, students, and developers who want to write their own analysis. Keep modeling close to your data and existing Python tools. The released package uses an earlier API than the Studio preview.

Pricing & use

Noncommercial use is free under the linked Prosperity Public License. Commercial use requires the applicable commercial permission; contact us to discuss a license. No paid Core price is published.

What you can get today

The public package is available now. Follow documentation matching the installed API; the new block API is still a development preview.

02 / For learning and researchPreview · access by request

Studio Community & Academic

Explore your scientific model in a visual workspace. See the structure, inspect quantities, and connect the model to its evidence.

Planned: free for noncommercial use

  • One proposed edition for community and academia
  • Visual modeling and inspection with CaliPy Core
  • Local agent integration is in development
Request preview access →
Fit, pricing & availability

Who it is for

For individual learning, teaching, and noncommercial research. Studio is the proposed product name for the workbench shown as Model Forge in the demo. Community and academic use share one proposed edition.

Pricing & use

The intended price is free for qualifying noncommercial use. Final eligibility, license terms, supported systems, and the release package are still being prepared. Academic affiliation alone does not make a commercial project noncommercial.

What you can get today

Try the browser demo today. Installable preview access is reviewed individually; there is no general Studio download yet. A request does not guarantee access or a release date.

Price to be announced

  • Discuss model delivery and support requirements
Discuss business access →
Fit, pricing & availability

Who it is for

For engineering teams, consultants, and companies developing instruments or delivering models to customers. Start with the measurement problem and the way the result needs to reach your team or client.

Pricing & use

Commercial use and selling your own models are intended use cases, subject to agreed terms. Redistribution or embedding of CaliPy itself needs separate agreement. Pricing, support, seat limits, and update terms are not finalized.

What you can get today

The commercial edition is being defined. You can discuss preview access or a scoped modeling pilot now; no checkout, subscription, or production support commitment is offered on this site.

04 / For your agents & infrastructurePlanned deployment offering

CaliPy Server

A proposed CaliPy runtime in your own AWS environment, where your agents can work with scientific models through explicit permissions.

Pricing under development

  • Customer-owned AWS deployment is the target
  • Bring your own agent host and AI provider
  • Separate model review from permission to execute
Discuss a server deployment →
Fit, pricing & availability

Who it is for

For teams that want agent workflows to reach a shared scientific runtime. The target is a customer-operated service, with access and execution scoped to the work you authorize. The current local bridge supplies a prototype of the interaction.

Pricing & use

Software pricing and commercial terms are not yet set. AWS infrastructure and any AI-provider usage would be separate customer costs. No public hosted inference service or remote MCP endpoint is currently available.

What you can get today

A local agent bridge exists as a development prototype. The AWS deployment product, remote access controls, distribution, and billing remain planned. Register interest to discuss the deployment you need.

The browser demo is free to explore without an account. It shows a fixed example and recorded results. It does not grant a software license or run new inference.

One model, several ways to work

How Core, Studio,
and agents connect.

Core supplies the scientific model. Studio presents it as an inspectable workspace. Agent integration works through the same model operations, with review and execution permissions kept explicit.

That shared foundation is the product direction. The released Core interface and current Studio development build are at different stages.
