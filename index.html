A look at the next interface

An unknown-mean model
in Python.

A prior describes an unknown level. A measurement law describes the readings. A block connects them. The scientific graph stays visible in Python.

DEVELOPMENT PREVIEW

This block API is from the current development checkout. The published package and documentation use an earlier interface.

Explore the development workflow →
unknown_mean.py · development API
import calipy as cp
import pyro.distributions as dist

# What is the level behind these readings?
level = cp.LatentParameter(
    "level", prior=dist.Normal(0., 2.)
)
measurement = cp.RandomVariable.Normal(
    "reading", scale=0.15
)

@cp.block
def model():
    return measurement(level())

Common questions
about CaliPy.

What is CaliPy?

CaliPy is a Python library for probabilistic instrument modeling and calibration, built on PyTorch and Pyro. It helps describe how measurements are generated, how scientific effects combine, and which quantities are uncertain.

What can I use today?

The public Python package is available as calipy-ppl, with source and documentation linked on this site. The newer block API, Model Forge, and optional agent bridge shown here are development previews. They are not all included in the published package.

Does CaliPy replace PyTorch or Pyro?

CaliPy builds on them. Torch provides tensor computation and differentiation; Pyro provides probabilistic inference. CaliPy adds structures for composing and inspecting scientific measurement models.

Is it production-ready?

CaliPy is pre-alpha research software. APIs may change. Validate a model against your scientific assumptions, use version-matched documentation, and inspect inference diagnostics before relying on results.

Can I use it commercially?

CaliPy uses the Prosperity Public License. Review the complete license terms for your intended use, and contact the project about commercial licensing or collaboration.

Can an AI agent run CaliPy?

Coding assistants can work with the public Python package and its documentation. An optional local MCP bridge exists as a development prototype; it is not a public hosted service or registry release. The agent guide explains the current boundaries.
